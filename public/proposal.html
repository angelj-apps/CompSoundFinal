Project proposal: Garden Groovebox

I propose building a Generative FM Groovebox: a 16-step browser instrument where each step triggers a short frequency-modulation (FM) voice, and where the player can both hand-edit patterns and ask the system to generate or mutate material under musical constraints. The primary category is automated composition, with DSP as the sound engine. Rather than a wall of sliders, timbre will be performed on a 2D pad (horizontal for ratio, vertical for index), so a sound is a place you move to. The instrument's centerpiece will be a living score: a canvas where every step is a mark that blooms when it sounds, drifts while unlocked, and writes its height back into the pattern as a scale degree once per bar, so the picture and the sequence compose each other instead of one merely displaying the other. Around that loop I plan two extensions if time allows: a resonance field that turns each sounding note into light colored by pitch and shaped by the carrier waveform, and a melody stack that saves a melody together with the whole instrument state around it so saved lines can loop underneath the one being edited. If the core is solid, I would also like the garden to have weather: a slow seasonal cycle that changes how restless the marks are, so the piece varies over minutes rather than settling into one texture.

This project applies three explicit learning targets from the course rubric. First, the class concept is FM synthesis: a modulator related to the carrier by a frequency ratio, with modulation depth controlling timbre. Second, the in-class Web Audio technique is using a GainNode as the modulation index, routing the modulator into the carrier's frequency AudioParam. Third, the outside-class technique is constrained probabilistic / Markov-style pattern generation: unlocked steps are rewritten inside a chosen scale and tonic, with density rules, optional transition bias learned from the current pattern, and a mutate mode that nudges pitches or rests. Step locks are the key interaction here: they let the player pin a motif and ask the machine to fill around it, making generation a collaborator with veto power rather than a one-shot randomizer.
